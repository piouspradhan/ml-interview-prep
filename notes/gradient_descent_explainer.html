the dataset m = 6 samples
X = [1, 2, 3, 4, 5, 6] ← house sizes (hundreds sqft)
y = [2, 4, 5, 4, 5, 6] ← prices ($100k)
θ = 0.0 ← initial weight (single feature, no bias for simplicity)
α = 0.01 ← learning rate
the update rule — batch uses ALL m samples every step
Gradient = (1/m) × Σᵢ (θxᵢ - yᵢ) × xᵢ
θ_new = θ - α × Gradient
step-by-step iteration 1
1
compute prediction for every sample: ŷᵢ = θ × xᵢ = 0×xᵢ = 0 for all i
2
compute error for each: (ŷᵢ - yᵢ) = [−2, −4, −5, −4, −5, −6]
3
multiply each error by xᵢ: [−2, −8, −15, −16, −25, −36]
4
sum and average: Gradient = (−2−8−15−16−25−36)/6 = −102/6 = −17.0
5
update: θ = 0.0 − 0.01 × (−17.0) = 0.17
6
repeat with new θ until convergence
code
import numpy as np

X = np.array([1, 2, 3, 4, 5, 6], dtype=float)
y = np.array([2, 4, 5, 4, 5, 6], dtype=float)
theta, alpha, m = 0.0, 0.01, len(X)

for epoch in range(100):
    predictions = theta * X # (m,) — uses ALL samples
    errors = predictions - y # (m,)
    gradient = (1/m) * np.dot(errors, X) # scalar
    theta = theta - alpha * gradient

print(f"θ = {theta:.4f}") # → θ ≈ 0.9167

import numpy as np

X = np.array([1,2,3,4,5,6], dtype=float)
y = np.array([2,4,5,4,5,6], dtype=float)
theta, alpha, batch_size = 0.0, 0.01, 2

for epoch in range(100):
    idx = np.random.permutation(len(X)) # shuffle
    X_s, y_s = X[idx], y[idx]

    for i in range(0, len(X), batch_size):
        Xb = X_s[i:i+batch_size]
        yb = y_s[i:i+batch_size]
        grad = (1/batch_size) * np.dot(theta*Xb - yb, Xb)
        theta = theta - alpha * grad

print(f"θ = {theta:.4f}")

import numpy as np

X = np.array([1,2,3,4,5,6], dtype=float)
y = np.array([2,4,5,4,5,6], dtype=float)
theta, alpha = 0.0, 0.01

for epoch in range(100):
    idx = np.random.permutation(len(X)) # shuffle
    for i in idx:
        xi, yi = X[i], y[i] # single sample
        grad = (theta*xi - yi) * xi
        theta = theta - alpha * grad

print(f"θ = {theta:.4f}")
